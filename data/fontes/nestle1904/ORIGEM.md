# Nestle 1904 (trecho avulso)

- Texto: *Novum Testamentum Graece*, Eberhard Nestle, 1904 (domínio público).
- Edição digital: https://github.com/biblicalhumanities/Nestle1904, commit `713f28a3b7d4d66132f5aa809fa223fe79762e5d`,
  arquivo `xml/06-romans.xml` (texto-base de Diego Renato dos Santos, que declara domínio público;
  a marcação morfológica do repositório é CC0).
- Uso no projeto: somente Rm 16,25-27 (doxologia final), ausente do SBLGNT. O arquivo `text/Rom-16-25-27.txt`
  contém apenas as palavras gregas desses três versículos, extraídas do XML acima (sem a morfologia).
